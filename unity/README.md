# ZIKJ Unity Project

Use this folder as the Unity project root.

Expected production layout:

- `Assets/Scripts/ZIKJ/` - gameplay, input, tracking, and mode scripts
- `Assets/Scenes/` - Unity scenes such as `InfectedArena`
- `Assets/Prefabs/` - kart, safe zone, HUD, and track prefabs
- `Packages/` - generated by Unity
- `ProjectSettings/` - generated by Unity

The current C# scripts are staged in `Assets/Scripts/ZIKJ/`.

Open this `unity/` folder in Unity Hub or create the Unity project here, then commit `Assets/`, `Packages/manifest.json`, and `ProjectSettings/`. Do not commit generated folders such as `Library/`, `Temp/`, `Obj/`, or builds.
