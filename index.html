PHASE 1 PROTOTYPE · BROWSER BUILD · PRE-UNITY
⚡
Everything here is a browser prototype. No Unity, no hardware, no install required — double-click any file and play. The projection-mapped visuals you see in each game mode are exactly what will be mapped onto the real track floor. Once game rules are validated here, this code is ported to Unity and projected via ceiling-mounted laser projectors.

Shared Code
All 5 game modes share engine.js — a single file containing: track geometry, kart physics, AI waypoint following, input handling, shared render helpers. Each mode adds only its specific rules (~200–300 lines). When porting to Unity, engine.js becomes a set of C# classes — the logic is identical, only the syntax changes.
